# NovaCore - Product Blueprint

# Purpose

This document defines the core building blocks of NovaCore before any
technical implementation.

## Product Identity

NovaCore is a Personal Digital Operating System built around Life Spaces
instead of folders.

## Core Objects

-   User
-   Workspace (future)
-   Life Space
-   Asset
-   Relationship
-   Tag
-   Reminder
-   Activity
-   Comment
-   Share

## Life Space Types

-   Home
-   Family
-   Work
-   Project
-   Travel
-   Health
-   Finance
-   Vehicle
-   Education
-   Collection
-   Blank

## Asset Types

-   File
-   Photo
-   Video
-   Document
-   Note
-   Password
-   Receipt
-   Invoice
-   Contact
-   Event
-   Certificate
-   Bookmark

## Relationships

Assets may belong to multiple Life Spaces through references. Spaces may
contain sub-spaces.

## Product Principles

-   Privacy First
-   One Search
-   Everything Connected
-   Modular
-   API First

## Engineering Decisions

-   Primary organization = Life Spaces
-   Files are assets, not the center of the product
