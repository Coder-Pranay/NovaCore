# NovaCore - Product Requirements Document (PRD)

## Version

-   Version: 0.1
-   Status: Draft

# Executive Summary

NovaCore is a Personal Digital Operating System that organizes a user's
digital life using Life Spaces.

# Product Goals

## Primary Goals

-   One home for digital assets
-   Privacy-first
-   Universal Search
-   Modular architecture

# In Scope (V1)

-   Authentication
-   Dashboard
-   Life Spaces
-   Files
-   Photos
-   Videos
-   Notes
-   Documents
-   Search
-   Sharing
-   Reminders

# Out of Scope (V1)

-   AI Assistant
-   Email
-   Browser
-   Marketplace
-   Social Network

# Success Criteria

-   Create Spaces
-   Upload Assets
-   Search Everything
-   Secure Sharing
