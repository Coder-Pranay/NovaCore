# NovaCore - Information Architecture

# Navigation

Dashboard ├── Spaces ├── Assets ├── Search ├── Shared ├── Activity ├──
Trash └── Settings

# Hierarchy

User └── Life Space ├── Sub-space ├── Assets ├── Members ├── Tags └──
Activity

# Asset Flow

Create Asset → Assign to Space → Add Tags → Link Relationships → Search
→ Share

# Search Scope

Search should return: - Spaces - Files - Photos - Videos - Notes -
Documents - Tags - Reminders - Contacts - Events

# Design Principle

Users think in terms of life, not folders. NovaCore should reflect that
mental model.
